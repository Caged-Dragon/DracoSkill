From a blank file to something you can show

  1. Write

    Pick Python, JavaScript, Java, C or C++ and start typing. Syntax colour, line numbers and auto-indent are built in. Log in to keep projects with several files.

  2. Run

    One press of Run compiles and runs your code on our servers. You get the real output, the real errors and how long it took.

  3. Solve

    Practise on problems judged against hidden test cases. When an answer is wrong, you see which test failed and what your program printed.

  4. Prove

    Solve every problem in the set and DracoSkill issues a certificate with a link anyone can use to check it.

A certificate that checks out

Each certificate is generated from your own submission history: problems solved, accuracy, number of attempts. It carries an ID and a QR code that open a page confirming it is real.
